# E001 실행 안내 / Runbook

## 현재 상태

2026-09-13: 설계와 E0 실험 장치 검증까지 완료. GitHub Actions에서 테스트 36개, 기준 계산 fixture 48회, 같은 SQL Capability의 변형 업무 전이 12건을 확인했다. 이것은 실제 AI 성능 비교가 아니다. 실제 모델 호출 0회, 실제 인간 작성 방법서 수집 0건이다. 실측 근거는 ../../evidence/E001/E0_RESULT.json을 읽는다.

## 연구 목표

같은 모델·도구·권한·목표에서 방법 설계 책임을 AI로 넘겼을 때, 결과 품질을 유지하면서 사람의 전체 준비·응답·검토·수정 시간을 줄일 수 있는 업무 조건을 찾는다. 최종 산출물은 '목표만 위임 / 사실 보충 / 인간 방법 필요 / 인간 실행·승인 유지'를 구분하는 위임 기준이다. BARE-GOAL 승리를 전제하지 않는다.

## 파일

- PROTOCOL.md: 연구 목표, 비교 정의, 지표, 통계/표본/재사용 설계와 중단 기준.
- CONFIG.template.json: 고정 모델/환경/예산/보류 항목. 현재 값은 의도적으로 미확정 상태다.
- HUMAN_GUIDE.template.json: 진짜 인간 작성 방법서의 출처·해시·준비시간 기록.
- ../../benchmarks/e001_tasks.py: 공개 개발용 합성 데이터 3종과 독립 Python 정답 계산.
- ../../implementations/e001_harness.py: 폐쇄형 읽기 도구, 질문 기록, 제출/평가 분리, Capsule 보관, 사전 게이트와 탐색용 adapter 연결부.
- ../../tests/test_e001.py: 정상/오답/권한/격리/누락 측정/오표기 방지 검사.
- ../../evidence/E001/E0_RESULT.json: 실제 원격 실행 근거.

## E0 재실행

저장소 루트, Python 3.10 이상에서 실행한다. 외부 Python 패키지나 모델 API 키는 필요 없다.

```sh
python -m unittest discover -s tests -v
```

다음 명령은 미확정 조건 때문에 종료 코드 2와 BLOCKED가 나오는 것이 정상이다.

```sh
python implementations/e001_harness.py preflight --config experiments/E001/CONFIG.template.json --guide experiments/E001/HUMAN_GUIDE.template.json
```

GitHub의 E001 instrumentation only 워크플로는 해당 연구 브랜치의 코드 변경 또는 관련 PR에서만 단위검증을 수행한다. 정기 작업, 모델 API 호출, 유료 모델 구독, 고객 연결, 배포는 하지 않는다. GITHUB_TOKEN은 read-only이며 결과를 저장소에 자동 push하지 않는다.

## 본실험 진입 조건

1. 개발 자료만 본 실제 인간 설계자의 방법서와 준비시간, 적합성/사실 동등성 검토 기록을 확보한다. 사람인 척 AI가 작성한 방법서는 사용하지 않는다.
2. 동일한 모델의 고정 backend와 reasoning 설정, 분리 세션, 요청 전 토큰/금액/시간 제한이 실제로 동작하는 실행기를 연결하고 별도 smoke test를 남긴다.
3. 전체 사람 개입시간(질문 응답뿐 아니라 준비/검토/수정 포함)을 측정하고, 자료·방법서·평가기·실행환경을 동결한 뒤 새로운 비공개 평가 입력을 만든다.

현재 `run_episode`는 adapter 연결을 개발하기 위한 동기식 탐색 함수다. 콜백 내부의 멈춤/결제 상한을 강제로 제어하는 별도 프로세스가 아직 없으므로 primary 결과를 출력하지 못하도록 의도적으로 막았다. 값만 채운 설정 파일은 동작 검증을 대신하지 않는다.

## 측정 구현 범위와 아직 남은 작업

이미 구현: 정확한 사업 출력 비교, 행 단위 F1, 출력 형식, 필수 인간 사실 조회 근거, 질문/중복 질문, 도구 오류, 출력 수정, 권한 위반, 입력 분리, Capsule 해시/실제 호출, 미측정 비용 null 유지, 실패 비용 포함 계산.

아직 검증되지 않음: 실제 모델 provider 어댑터, 선제적 live budget 차단, 전체 인간 활동시간 수집기, 맹검 인간 검토, 비공개 본실험 케이스, 실행 순서 무작위화 orchestration, task-cluster 통계 분석기. 프로토콜에 계획된 기능과 구현 완료 기능을 혼동하지 않는다.

설계상 첫 파일럿은 12개의 새 A/B 업무쌍 × 3회 × 2조건 × (A, B-warm, B-cold) = 216회다. 이는 계획이며 실행 완료 수가 아니다. 12개 업무를 3회 반복해도 독립 업무 표본이 36개가 되는 것은 아니다. 작은 파일럿으로 5%p 비열등성을 입증했다고 주장하지 않는다.

## 공개/비공개 경계

이 패키지는 일반 연구 설계·합성 입력·자체검증 결과만 포함한다. 다른 비공개 저장소의 설계나 고객 정보는 복사하지 않았다. 실제 인간 참여 기록, 비밀키, 사내 자료, 평가 완료 전 held-out 입력·정답은 공개 저장소에 올리지 않는다. 기존 이론 README를 검증된 결론으로 변경하지 않았다.
